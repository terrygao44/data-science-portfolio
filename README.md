# data-science-portfolio

My data science portfolio, published with GitHub Pages from this repository.

**Live site:** <https://terrygao44.github.io/data-science-portfolio/>

The site is a single `index.md` at the root of the repository, which GitHub Pages
builds into the home page. Images live in `assets/`.

## Contents

| File | Purpose |
|---|---|
| `index.md` | The portfolio page: introduction, technical skills, project showcase |
| `assets/macau-recovery-index.png` | Main figure from the featured project |
| `assets/macau-scale-vs-recovery.png` | Companion figure on market size vs recovery |

## Featured project

**Who came back to Macau?** — post-pandemic recovery of visitor arrivals by
source market. Code, data and full documentation:
<https://github.com/terrygao44/data-science-project>

## How this site is published

Settings → Pages → *Deploy from a branch* → branch `main`, folder `/ (root)`.
GitHub Pages serves `index.md` from the repository root as the site's home page.
